# Android OCR models

The Android PaddleOCR SDK expects model assets at these paths:

- `models/det/inference.onnx`
- `models/rec/inference.onnx`
- `models/rec/inference.yml`

These are the official PP-OCRv5 mobile ONNX assets. Their SHA-256 values are
recorded in `models/SHA256SUMS` for release verification.
